Methodology FAQ

What does Native mean?

Native means the feature is built into the platform or is clearly first-party.

What does Official mean?

Official means the feature is an officially supported integration or tightly supported ecosystem feature, even if it is separate from the core product.

What does Third-party mean?

Third-party means the capability usually requires an external product, plugin, script, or custom setup.

What does No or not found mean?

No or not found means no official native feature was found in the current docs reviewed for the comparison.
